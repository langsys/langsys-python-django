**Profile.** The spec's per-SDK profile table rows this package `server, binding` over `langsys-python`,
with terminal HTML. So it takes the server rules through its core, the binding rules itself, and the SRV
family for the render it performs inside a request. Every profile-based `n/a` below is checked against
its rule's own Profiles line by `test_profile_rows_agree_with_each_rules_profiles_line`.

**Evidence tiers follow CONF-2.** `live`, `contract` and `mock` apply only where the governed property
depends on what the API answers. Everything this binding owns is an in-process property: which locale
a request is served in and what its response says it varied on, whether its page is marked resolved,
when the core's scope, flush and reset run relative to Django's lifecycle, what the tag hands the core,
and what the code does not contain. So every binding-owned row is `n/a (pure)`. Every property that does
depend on the API is the core's, and its row is `delegated`, with tier `-` and the core's own grade
named in the evidence.

## What surfaced while writing this

1. **The middleware decided capability itself (BIND-2, GATE-2).** It collapsed an unreachable authorize
   into "no" and discarded a queue the core would have held. *(Reviewer.)*
2. **The write decision survived the request (GATE-3).** A later request acted on an earlier request's
   decision, and the OBS-1 notice fired once per process. *(Reviewer.)*
3. **Registration ran on the request path (SRV-3, REG-3).** *(Reviewer.)*
4. **`AUTO_FLUSH` was a binding-only discovery switch (BIND-4).** *(Reviewer.)*
5. **A streamed response rendered in the base language, and its misses were never sent.**
6. **`{% t %}` turned an undefined template variable into `""` (BIND-1, ICU-2, ICU-3),** so the core
   rendered `Hi !` where it renders the visible gap `Hi {name}!`, and a plural leaked its raw ICU source.
7. **The core's debounce and process-wide queue could send a request's misses before its response was
   out (SRV-3).** The core's request scopes (`1229ca2`) close it, and the middleware opens one per request.
8. **Two of this binding's tests could not fail at first, and mutation showed it**: an SRV-2 test with one
   barrier, and a debounce test that raced a sleep against a timer.
9. **Probes can misfire in both directions.** One matched Django's `var.resolve(context)`, another Django's
   `django.utils.cache` import, and a control stopped firing when the core's live tree moved the code it
   pointed at. Probes read the package as imported, match the core's own forms, and take their controls
   from the modules that define what they probe.
10. **`t()` and `{% t %}` cannot pass a placeholder named `category` or `phrase` (BIND-1).** The core's
    `params` mapping can. Measured in the FastAPI lane first and confirmed here.
11. **No response said it varied by locale.** One URL served several languages with no `Vary`, which a
    shared cache turns into a cross-serve; the Rails lane reproduced it on a CDN. SRV-6 closes it here:
    the middleware resolves the locale through the core and adds the `Vary` headers the choice names.
12. **A live core tree is not a pinned one.** A local run went red while the core's mutation harness was
    rewriting its source in place. The core now mutates an isolated copy, and this file's evidence is the
    run against a clean archive of the core.
